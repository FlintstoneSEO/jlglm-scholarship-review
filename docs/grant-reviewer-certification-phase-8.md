# Business Growth Grant reviewer certification — Phase 8

Phase 8 uses the six existing consistency and conflict expectations in `GrantConsistencyGuidance`. The final checkbox records `grant_reviewer_certification_v1`. It confirms the review process and disclosure according to program policy; it does not declare that no conflict exists. The portal has no separate conflict disclosure or recusal workflow, so this phase does not assert that a disclosure was independently resolved.

The canonical Grant submission RPC accepts a certification version and explicit confirmation for final submit only. It validates the active assignment, eligibility gate, active 100-point rubric, exact valid scores, current review version, and certification before updating the review. An append-only `grant_review_certifications` row records the review, reviewer, version, key, and timestamp within the same transaction. Draft saves require no certification. Reopening increments the review version, leaving prior certification history attributable while requiring a new confirmation on resubmission. The browser clears its checkbox after score or comment edits; the RPC binds the confirmation to the exact payload and optimistic review version it submits. The existing idempotency key includes certification inputs so a replay cannot change the certification claim.

Only the assigned actor with current reviewer or administrator program access can submit through the existing RPC, including an assigned program admin. The role check is reinforced by `20260928000001_grant_certification_role_gate.sql` because an assignment may remain after a role change. Direct table writes are not granted. Certification reads are limited to the reviewer and authorized program administrators through RLS. Scholarship submission and recommendation are untouched. The funding recommendation remains derived from score and does not select a recipient.

Historical completed Grant reviews display the rubric version stored on the review. Open reviews use the active rubric. A completed review from before Phase 8 has no certification row and displays that the certification is not recorded; history is not fabricated.
