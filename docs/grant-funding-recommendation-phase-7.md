# Business Growth Grant funding recommendation — Phase 7

The approved Grant recommendation is decision support in the Rubric summary. A complete, valid score on a 100-point rubric produces one of five tiers and four reviewer-facing recommendations. Competitive and Marginal both map to Consider; Marginal includes the approved funding-availability guidance. Missing criteria, invalid points, and non-100-point rubrics produce no recommendation. No recipient selection follows from this calculation.

The canonical calculation is `getGrantFundingRecommendation` in `src/lib/grant-funding-recommendation.ts`. `grantFundingRecommendationState` applies the current `grantReviewSummary` completion, validity, and maximum-point gates. The Rubric summary presents the recommendation, tier, score, and any guidance as text after review progress. It shows a Pending state for incomplete/invalid scoring and a configuration message when the rubric maximum is not 100. The readiness checklist reports calculation state but does not add a submission condition or confirmation action. The Application view keeps its existing answer-and-criterion focus. Submitted reviews use their stored scores and their own rubric version's criteria if the active version has since changed.

The canonical `submit_business_grant_review` function persists `review_scores` and the `program_reviews` status. The recommendation is deterministic from those scores and its rubric version, so Phase 7 does not add a database column or migration. Existing eligibility, assignment, Save Draft, Submit Review, and Scholarship recommendation behavior remain unchanged. A later committee view can call the same score helper for an average, provided it explicitly checks that the scored rubric is the approved 100-point Grant rubric.
